# Evidence Guide

## What the Task Explicitly Requires

The uploaded task requires final checks using:

```bash
tree project
```

and:

```bash
ls -la
```

The purpose is to confirm:
- file permissions are correctly set
- files are in the correct locations

The task does **not** explicitly require screenshots, so screenshots in this repository are optional organizational placeholders rather than mandatory evidence.

## Suggested Evidence

If you choose to capture screenshots for your own record, useful filenames include:

- `01-user-confirmation.png`
- `02-project-structure.png`
- `03-report-and-secret-files.png`
- `04-permissions.png`
- `05-final-tree.png`
- `06-final-ls-output.png`

These filenames are suggestions only and are not additional requirements from the activity.

## Terminal Output

The `terminal-output/` folder can hold actual output copied from your Kali session.

Do not fabricate output.

## Final Evidence

At minimum, preserve your actual final results from:

```bash
tree project
```

and the relevant:

```bash
ls -la
```

checks.

If you use the optional history task, preserve the actual `commands_used.txt` generated from your session.
