# Submission Guide

## What the Uploaded Task Specifies

The activity does not provide a separate mandatory submission checklist. It specifies final checks and an optional bonus.

### Final checks
Run:

```bash
tree project
```

Then use `ls -la` to confirm:
- permissions are correctly set
- files are in the correct locations

### Optional bonus
Run:

```bash
history
```

and optionally redirect it to:

```text
commands_used.txt
```

in the home directory using `>`.

## Submission Files in This Repository

This folder provides optional places to preserve your actual work:

- `commands_used.txt` — actual history output if you complete the bonus.
- `final-tree.txt` — actual `tree project` output.

These are templates/placeholders only. Replace them with your real results if you want to keep them with the project.

Do not submit fabricated output.
